# 지식 반영·승격

대화·리뷰·실수에서 나온 내용을 **Git에 남겨** 다음 작업에서 AI가 다시 읽게 한다.
모델이 “기억”하는 것이 아니라, 이 저장소의 `.ai` 파일이 학습 데이터다.

## 즉시 반영 (같은 작업)

사용자·리뷰에서 **지적된 실수**나 **확정된 사실**은 코드 수정과 **같은 작업**에서 파일에 적는다.

| 내용 | 적을 곳 |
|------|---------|
| 특정 앱·도메인 (용어, 불변 조건, 금지 사항) | `.ai/projects/{앱}.md` |
| 스택·공통 코딩 (Java, React, API 등) | `.ai/rules/{해당}.md` |
| 입구·읽기 순서·레이아웃 | `AGENTS.md` |

- 한 줄이라도 남긴다. “나중에”만 남기지 않는다.
- `README.md`, `docs/` 는 **근거가 아니다.** 반영 후 사람용 문서만 필요하면 같은 작업에서 최신화한다.

## 공통으로 승격 (사람 승인)

`.ai/projects/` 또는 한 앱 전용 내용이 **다른 앱·스택에도 통한다**고 확신될 때만 `.ai/rules/common.md` 등 **공통 rules** 로 올린다.

- AI는 승격 **후보와 근거만 제안**한다. 승격·문구 확정은 **사람이** 한다.
- 이름이 비슷하거나 한 앱에서만 맞는 내용은 공통으로 올리지 않는다.
- 승격 시 앱 전용 표현·경로는 분리한다.

## 하지 않는 것

- 대화만 하고 파일에 남기지 않기
- 확인 없이 rules 전체에 장문 복붙
- `docs/` 내용을 구현 근거로 쓰기

## Cursor 전용 (선택, 나중)

`.cursor/rules/*.mdc` glob 으로 경로별 자동 첨부는 **Cursor 보조**다. Claude·Copilot 은 `AGENTS.md` + 이 파일 + 위 표를 따른다.
