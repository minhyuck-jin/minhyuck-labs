# `.ai/projects`

AI가 코드를 이해할 때 읽는 **업무·도메인** 설명이다.

## 규칙

- 공통 코딩 규칙은 `../rules/` 에 둔다.
- 앱 추가 시 `{앱 id}.md` 를 둔다. 사람용 소개·경력은 `docs/` 에 둔다.
- 스택·버전 **본문**은 여기만 둔다. 명령·Read 순서는 `{앱}/AGENTS.md` (`../rules/common.md` 「하네스 작성」).
