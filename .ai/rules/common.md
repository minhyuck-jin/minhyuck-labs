# 공통 기술 규칙

모든 스택에 적용한다.

## 파일

- 소스와 텍스트는 UTF-8.
- 개행은 LF. CRLF가 섞이지 않게 한다 (`.gitattributes`, `.editorconfig`).
- 파일 끝은 개행으로 끝낸다.

## 이름

- 식별자는 영문, 숫자, 언더스코어만 쓴다.
- 한글 발음을 영어로 옮긴 이름은 쓰지 않는다.
- 이름이 의미를 드러내게 한다. 한 글자 이름은 짧은 범위의 임시 변수만 허용한다.

## 환경·스택

환경 세팅·스택 선택·코드 형태·**프로젝트 성숙도**에 적용한다.

1. 업계·현행
   - 메이저 스택·도구는 **업계에서 쓰이는 현행**을 따른다. 구세대 예제만을 **그대로** 기본으로 두지 않는다
2. 검증된 최신
   - **공식 registry·릴리스** 기준 **최신**을 쓰되, peer 불일치·`build`·`test`·`lint` 미확인·치명 리스크가 있으면 **채택하지 않는다**
   - 새 도구·메이저 버전·`lint`·`format` 도입도 위와 같다. 같은 파일·다른 파일 모두 **동일 정책 본문 재서술 금지**
3. 실무 규모
   - 이 저장소는 **대규모 서비스**와 같은 스펙을 가정한다. 코드 스타일·라이브러리·구현 방식은 업계 **현행 표준**으로 처음부터 둔다. 프론트도 같다
   - monorepo·품질 게이트(CI·`lint`·`test`)·API·운영 가정을 그 스펙에 맞춘다
4. AI·하네스
   - 규칙·도메인은 Git·hook·CI에 남기고 **검증 보고**한다. 양식·점검·지적 반영: 아래 「하네스 작성」·`.ai/KNOWLEDGE.md` 「지적 반영」
5. 외부 템플릿
   - 공개 starter·boilerplate **전체 복붙**은 사용자 요청 없이 하지 않는다. 스택·검증은 `projects/`·lock·CI로 맞춘다

## 작업 방식

- 요청한 범위만 수정한다. 추측으로 구현하거나 범위를 넓히지 않는다.
- 설명·이해·비교(「왜」「맞나」「이게 아냐?」 등)만 묻는 메시지는 **답변만** 한다. 코드·설정·하네스 변경은 사용자가 구현·적용·되돌려 달라고 **명시한 뒤**에 한다.
- 수정 전에 관련 기존 코드를 읽는다. 없는 API·설정·테이블을 있는 것처럼 쓰지 않는다.
- 확신이 없으면 추측하지 말고 선택지를 물어본다.
- 표준·방법 질문과 구현은 그 스택의 **현행 공식 문서**를 확인한 뒤에 답하고 코드에 반영한다. 확인하지 않은 추측·개인 추천을 표준이라고 말하거나 구현하지 않는다. 공식 문서가 여러 구성을 허용하고 순위를 두지 않으면 순위가 없다고 답한다. 다른 저장소 코드는 근거로 쓰지 않는다.
- **Pending**(사용자 미답)으로 남긴 선택·질문은, 답·승인 전에 반영하지 않는다.
- 헬퍼·공통 유틸·추상 계층은 기본으로 만들지 않는다. 필요하면 장단점을 말하고 동의를 받는다.
- 변경 후 해당 모듈의 테스트, 빌드, 린트가 있으면 실행한다. 없으면 실행 방법만 적는다.

## 하네스 작성

저장소 **모든 `.md`** (`.ai/` · `AGENTS.md` · `CLAUDE.md` · `README.md` · `docs/` · `.github/copilot-instructions.md` 등)에 적용한다. (선택) `.cursor/rules/*.mdc` 도 블록 타입을 맞춘다. **작성·수정 전** 이 절을 Read 한다.

### 계층 (단일 출처)

| 파일 | 역할 | 본문 |
| --- | --- | --- |
| 루트 `AGENTS.md` | 입구·앱 지도·Read-before-write·하네스 검증 | 전역 규칙·지도 (스택 숫자 본문 없음) |
| `.ai/rules/` | 스택·언어 **공통** | `common.md` 「하네스 작성」·「환경·스택」. 앱 경로·package·DB·ORM **본문 금지** |
| `.ai/projects/{앱}.md` | 앱 DB·프레임워크·버전·설정 | **앱 사실 단일 출처** |
| `{앱}/AGENTS.md` | `npm run` · `./gradlew` · convention | 명령·포인터 (스택 본문 복붙 금지) |
| `CLAUDE.md` | Claude → `AGENTS.md` | 규칙 복사 금지 |
| `.cursor/rules/*.mdc` | Cursor glob Read 목록 | 규칙 전문 복사 금지 |
| `.github/copilot-instructions.md` | Copilot → `AGENTS.md` | 규칙 복사 금지 |
| `.ai/KNOWLEDGE.md` | 지적 반영·승격 **절차** | 사실·규칙 본문 금지 |
| `README.md` · `docs/` | 사람용 | 구현 **근거 아님** |

추가 harness 파일은 **필요할 때만** 만든다. 역할이 겹치면 **한 파일로 통합**한다.

### 중복

- **같은 파일:** 겹치는 정책·사실 **본문**은 **한 곳**에만 둔다. 줄일 수 있으면 **합치고** 반복 문장·표는 삭제한다. 같은 파일 안에서 「다른 절과 같다」 **포인터만** 남기는 것으로 중복을 대체하지 않는다.
- **파일 간:** 사실·규칙 **본문**은 **단일 출처** 파일에만 둔다. 다른 파일은 그 경로·섹션 **포인터**만 (일관성·Read 시 토큰). 역할·출처: 위 **계층** 표.
- `scripts/harness/check.sh`는 **동일 줄** dup(25자+)·**prose**·**표**·`### 사실`·rules `### 규칙`·**층 위반**·`scripts/harness/semantic-dup.py`(명령·포트·URL·입구 문장 등 **의미 중복**)을 검사한다. 표 `|` 행은 줄 dup에서 제외. 위 **중복** 두 불릿이 의미 중복의 기준이다.

### 블록 타입

| 타입 | 형식 | 쓸 내용 |
| --- | --- | ---- |
| 입구 | 서술 1~2문장 | 파일 역할 |
| 사실 | 표 (`##` 아래 **표만**이면 `### 사실` 없음) 또는 `### 사실` + 표 | 경로, 포트, 버전, URL |
| 규칙 | `##` 아래 불릿 또는 규칙·내용 2열 표 | must / must not |
| 절차 | 번호 목록 | bootstrap, Read 순서 |
| 금지 | `## 하지 않는 것` 표 | 건드리지 말 것 |
| 포인터 | 한 줄 | 본문: `path` |

### Markdown · prose

- 표 **`| ` 열 정렬**(공백 패딩)은 **헤더·본문 모든 셀에 한글이 없을 때만** 한다 (영문·숫자·기호·백틱 경로·`TO-DO` 등). 한글(또는 한글 섞임) 표는 **패딩하지 않는다** — `| 항목 | 값 |` + `| --- | --- |` 형태. 한글에 열 맞추기는 고정폭에서 깨진다.
- `scripts/harness/align-tables.py --fix` · `check.sh` 표 검사가 위 규칙을 적용한다.
- 표 헤더는 레포 `.md` 전체에서 **`항목 | 값`**, **`규칙 | 내용`**, **`파일 | 역할`** 등 **같은 역할끼리 동일 헤더**를 쓴다.
- prose **한글**. 경로·명령·`Read` · `TO-DO` 는 **영문 그대로** (백틱).
- harness `-` 불릿은 **마침표**로 끝낸다. `.ai/rules/api.md` 「HTTP 메서드」의 `조회: GET` 같은 한 줄 enumeration 은 예외.
- 한 단어 안 **한·영 접합** 금지. `lint`·`format`·Prettier 또는 린트·포맷.
- **긍정 기준**. 채용·포폴·이력 홍보 harness 금지. 변명·대화체 금지.
- **`### 사실`**: 같은 `##` 안에 **표·코드 블록과 불릿이 함께** 있을 때만 표·코드 앞에 쓴다. `##` 아래 **표(또는 코드)만**이면 **`### 사실` 없이** 바로 둔다.
- **`### 규칙`**: 같은 `##` 안에 **`### 사실`(표)·코드 블록과 규칙 불릿이 함께** 있을 때만 쓴다. `.ai/rules/*.md`처럼 `##` 아래가 규칙만이면 **`### 규칙` 라벨 없이** 불릿만 둔다.

### nested `AGENTS.md` 양식

1. `# AGENTS.md — {앱 id}` + 입구 1문장  
2. `## Build & test` — shell + `### 사실` 표 + `### 규칙`  
3. `## Read (이 모듈 수정 시)` — 번호  
4. 모듈 convention (해당 시)  
5. `## 하지 않는 것`  
6. 본문 포인터 → `.ai/projects/{앱}.md`

### `.ai/projects/{앱}.md` 양식

1. `# {앱 id}` + 입구 1~2문장 + 모듈 입구 포인터 (`{앱}/AGENTS.md`)  
2. `## 위치·빌드` — `| 항목 | 값 |` (표만이면 `### 사실` 없음)  
3. 주제별 `##` — 불릿만, 또는 표·코드와 불릿이 **같은 `##`** 이면 `### 사실` + 표·코드 (표·코드 뒤 불릿은 라벨 없이)  
4. `## 설정` — 표·불릿이 같으면 `### 사실` + `| 파일 | 역할 |`, 표만이면 표만  
5. `## 아직 없음` — 불릿

### `.ai/rules/*.md` 양식

1. `# … 규칙` + 입구 1~2문장  
2. 주제별 `##` + 불릿 (`### 규칙` **없음**)  
3. 표가 필요하면 `### 사실` + 표 (한 `##` 안에 표·불릿이 같으면 표 아래 불릿만)  
4. 금지 목록은 `## 하지 않는 것` + `| 금지 | 내용 |`

### 근거 · 사용자 설명

- 구현·분석 근거는 **코드와 `.ai` 뿐**이다. 하네스·구조 변경 시 `README.md` · `docs/` 를 같은 작업에서 맞춘다.
- 사용자-facing 채팅에서 repo 경로는 **전체** `file://` 링크 (harness 본문 필수 아님).
