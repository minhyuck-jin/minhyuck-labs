# 품질·안전 규칙

언어와 무관하게 코드를 생성·수정할 때 적용한다.
스택별 구현 방법은 `java.md`, `react.md` 를 따른다.

## 입력과 값
- 외부에서 들어온 값(요청 파라미터, 파일, 외부 응답)은 사용 전에 null·형식·범위·길이를 확인한다
- 검증에 실패하면 의미가 드러나는 예외로 끊는다. 잘못된 값을 그대로 흘려보내지 않는다
- null 여부를 확인하지 않고 바로 속성에 접근하지 않는다
- 비교는 null 이어도 깨지지 않는 방향으로 쓴다 (상수를 왼쪽에 두는 등)

## 리소스와 예외
- 파일·커넥션·스트림은 자동 해제 구문으로 닫는다
- 예외는 기록·복구·전파 중 하나를 한다. 비어 있는 catch 를 두지 않는다
- 잡을 예외는 구체적인 타입으로 잡는다. 최상위 예외로 뭉뚱그리지 않는다

## 비밀과 로그
- 비밀번호, API 키, 토큰을 소스에 하드코딩하지 않는다. 환경변수나 설정으로 주입한다
- 로그에 비밀번호, 토큰, 인증 헤더, 개인정보를 남기지 않는다
- 요청·응답 객체를 통째로 로그에 찍지 않는다

## 외부 연동
- 외부 호출에는 연결·응답 timeout 을 설정한다. 무한 대기를 두지 않는다
- 실패했을 때의 처리(로그, 예외, 대체 동작)를 함께 정한다

## 쿼리와 명령
- SQL 과 OS 명령을 문자열 결합으로 만들지 않는다
- 값은 파라미터 바인딩으로 전달한다

## 상태와 동시성
- 전역·static 가변 상태를 최소화한다. 불변 객체를 우선한다
- 공유 자원을 다루면 동기화 또는 동시성에 안전한 타입을 쓴다

## 기본값
- 기본값은 안전한 쪽으로 둔다. 검증 우회, 약한 암호화, 과도한 권한을 기본으로 두지 않는다
