# SQL·DB 규칙 (공통)

모든 앱·모듈의 SQL·스키마 작업에 적용한다.

**DB 종류, ORM, migration 경로, Mapper 패키지** 등 앱별 선택은 **`.ai/projects/{앱}.md`** 와 해당 모듈 `AGENTS.md` 에만 둔다. 이 파일에 넣지 않는다.

## Flyway (migration 도구를 쓸 때)

- 파일명: `V{버전}__{설명}.sql` (버전은 단조 증가).
- **한 번 적용된 migration 파일은 수정하지 않는다.** 변경은 새 버전 파일로 추가.

## SQL 작성

- 값은 **`#{}` 파라미터 바인딩** (`.ai/rules/quality.md` — 문자열 결합 금지).
- `${}` 는 식별자(컬럼·테이블) 동적 처리 등 **필요할 때만** 쓰고, 사용자 입력을 직접 넣지 않는다.
