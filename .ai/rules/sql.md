# SQL·DB 규칙 (공통)

모든 앱·모듈의 SQL·스키마 작업에 적용한다.

**DB 종류, ORM, migration 경로, Mapper 패키지** 등 앱별 선택은 **`.ai/projects/{앱}.md`** 와 해당 모듈 `AGENTS.md` 에만 둔다. 이 파일에 넣지 않는다.

## Flyway (migration 도구를 쓸 때)

- 파일명: `V{버전}__{설명}.sql` (버전은 단조 증가).
- **한 번 적용된 migration 파일은 수정하지 않는다.** 변경은 새 버전 파일로 추가.

## SQL 작성

- 값은 **`#{}` 파라미터 바인딩** (`.ai/rules/quality.md` — 문자열 결합 금지).
- `${}` 는 식별자(컬럼·테이블) 동적 처리 등 **필요할 때만** 쓰고, 사용자 입력을 직접 넣지 않는다.
- SQL 키워드·테이블·컬럼은 대문자다. `#{}` 변수명만 소문자다. `jdbcType` 등 파라미터 타입은 대문자다.
- 쿼리 본문은 태그보다 스페이스 4칸 들여 쓴다. `SELECT`·`UPDATE`·`INSERT`·`DELETE`·`FROM`·`WHERE`·`AND`·`ORDER BY`·`GROUP BY`·`HAVING` 은 그 칸에서 왼쪽을 맞춘다.
- `SELECT`·`UPDATE`·`INSERT`·`DELETE` 줄은 힌트 자리라 비워 둔다. 컬럼은 그 다음 줄, 쿼리 블록 시작에서 스페이스 8칸에 둔다.
- 이어지는 컬럼의 선행 콤마 뒤에는 공백 한 칸을 둔다. 컬럼 이름 시작은 첫 컬럼과 맞춘다.
- `FROM`·`WHERE`·`AND` 는 힌트 자리가 아니다. 테이블·조건을 같은 줄에 두고, 시작 위치를 컬럼 이름 시작과 맞춘다.
- `WHERE` 는 `1 = 1` 다음에 `AND` 로 조건을 붙인다. `AND` 는 `WHERE` 와 왼쪽을 맞춘다.
